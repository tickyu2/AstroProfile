## 🔄 INTELLIGENT ROUTING LOGIC

### Decision Tree for Query Routing:

```
Is this a NEW user profile calculation?
├─ YES → Use OPUS 4.5
│   ├─ Calculate full BaZi
│   ├─ Generate Western chart
│   ├─ Create compatibility baseline
│   └─ CACHE all results (never recalculate)
│
└─ NO → Is this a critical decision?
    ├─ YES → Use OPUS 4.5
    │   ├─ "Help me choose between..."
    │   ├─ Deep compatibility analysis
    │   ├─ Life phase predictions
    │   └─ Major relationship decisions
    │
    └─ NO → Is this conversational/interactive?
        ├─ YES → Use SONNET 4.5
        │   ├─ AI SoulMate daily chat
        │   ├─ Guidance and support
        │   ├─ Explanations of results
        │   ├─ Philosophical discussions
        │   └─ Educational content
        │
        └─ NO → Is it a simple lookup?
            ├─ YES → Use HAIKU 4.5
            │   ├─ "What sign is X date?"
            │   ├─ Element lookups
            │   ├─ Basic calculations
            │   └─ Validation checks
            │
            └─ Default → Use SONNET 4.5
```

### Pseudocode Example:

```python
def route_query(query_type, user, query_content):
    # Critical calculations - always Opus
    if query_type in ["new_profile", "bazi_full", "chart_deep", "compatibility_report"]:
        model = "opus-4.5"
        cache_key = f"{user.id}:{query_type}"
        
        # Check cache first
        if cached_result := get_cache(cache_key):
            return cached_result
            
        result = call_opus(query_content)
        set_cache(cache_key, result, ttl=PERMANENT)
        return result
    
    # Critical decisions - always Opus
    elif query_type in ["help_choose", "major_decision", "life_phase_analysis"]:
        model = "opus-4.5"
        return call_opus(query_content)
    
    # Simple lookups - use Haiku
    elif query_type in ["lookup", "validation", "simple_calc"]:
        model = "haiku-4.5"
        return call_haiku(query_content)
    
    # Everything else - use Sonnet
    else:
        model = "sonnet-4.5"
        return call_sonnet(query_content, user_context=get_user_context(user))
```

## 🚨 RISK MITIGATION

### Potential Issues & Solutions:

#### Risk 1: Opus Cost Explosion
**Scenario:** Users repeatedly request fresh analyses
**Mitigation:**
- Aggressive caching (99% cache hit rate)
- Rate limiting (1 deep analysis per week per user)
- Tiered pricing (unlimited Opus only in Premium)
- Education ("Your profile doesn't change daily")

#### Risk 2: Sonnet Quality Insufficient
**Scenario:** Users complain Sonnet conversations shallow
**Mitigation:**
- Provide Sonnet with comprehensive Opus-generated context
- Fine-tune prompts for depth
- Enable access to cached Opus analysis during conversation
- Hybrid approach: Sonnet asks Opus for deep questions

#### Risk 3: Model Parity Loss
**Scenario:** Users notice quality differences between models
**Mitigation:**
- Frame as "different AI personalities" not "worse AI"
- Emphasize strengths of each (Opus=depth, Sonnet=warmth)
- Never expose model names to end users
- Consistent quality thresholds across models

#### Risk 4: Haiku Errors
**Scenario:** Simple lookups give wrong answers
**Mitigation:**
- Validate Haiku results against database
- Use Haiku only for deterministic lookups
- Fall back to Sonnet if confidence < 90%
- Monitor error rates continuously
