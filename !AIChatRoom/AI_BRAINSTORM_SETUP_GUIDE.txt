✏️ CUSTOMIZING TOPICS FOR YOUR CURRENT FEATURE
═══════════════════════════════════════════════════════════════════════

You can add your own brainstorming topics!

1. Open AI_Brainstorm_AstroProfile.html in a text editor (VS Code, Notepad++)

2. Find this section (around line 65):
   ```javascript
   const ASTROPROFILE_TOPICS = [
   ```

3. Add your topic:
   ```javascript
   {
     id: 'my-feature',
     title: "My Feature Name",
     description: "What problem are we solving?",
     starter: "The opening question to discuss...",
     category: "Phase X"
   },
   ```

4. Save the file

5. Refresh browser (or reopen)

Done! Your topic appears in the list!

═══════════════════════════════════════════════════════════════════════
❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: AIs not responding
Solution: Check browser console (F12) for errors
          Make sure you're online (needs API access)

Problem: Topics don't show after editing
Solution: Hard refresh (Ctrl+Shift+R) or clear cache

Problem: Export doesn't work
Solution: Browser may block downloads - check popup blocker

Problem: Looks broken
Solution: Make sure you're opening in a modern browser
          (Chrome, Firefox, Edge - not IE!)
