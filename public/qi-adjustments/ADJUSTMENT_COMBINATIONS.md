# Combinations, Harmony & Void (合化) — Classical BaZi Interactions

Before the controlling cycle (clashes) fires, the engine checks for **classical
combination patterns** that can transform elements, suppress clashes, and reshape
the entire Qi landscape.

---

## 1. Heavenly Stem Combinations (天干合)

Five pairs of stems that naturally bond:

| Pair | Result | Classical Name |
|------|--------|----------------|
| 甲 + 己 | Earth | 中正之合 |
| 乙 + 庚 | Metal | 仁义之合 |
| 丙 + 辛 | Water | 威制之合 |
| 丁 + 壬 | Wood | 淫慝之合 |
| 戊 + 癸 | Fire | 无情之合 |

### Rules
- If both stems appear in chart + transit → combination activates
- If season supports the resulting element → **transform** (Qi shifts)
- If season does not support → **bond only** (noted but no Qi change)

### Effects (Transform)
- Reduce original stem elements by ~8%
- Boost resulting element by ~14% of total Qi
- Suppress clashes involving the paired stems

---

## 2. Earthly Branch Six Combinations (六合)

Six pairs of branches that naturally attract:

| Pair | Result |
|------|--------|
| 子 + 丑 | Earth |
| 寅 + 亥 | Wood |
| 卯 + 戌 | Fire |
| 辰 + 酉 | Metal |
| 巳 + 申 | Water |
| 午 + 未 | Fire |

### Rules
- If both branches appear → combination activates
- Void branches **cannot** combine (blocked)
- If season supports → transform
- If not → bond only (but still protects from clashes)

### Effects (Transform)
- Drain ~10% from each original branch element
- Boost ~18% of total Qi to resulting element
- Mark both branches as "protected" (clashes softened)

---

## 3. Three Harmony (三合局)

Triads of branches that form powerful elemental frames:

| Triad | Result |
|-------|--------|
| 申 + 子 + 辰 | Water |
| 亥 + 卯 + 未 | Wood |
| 寅 + 午 + 戌 | Fire |
| 巳 + 酉 + 丑 | Metal |

### Rules
- **Full (3/3)** + season support → strong transformation
- **Full (3/3)** + no season → bond with partial boost
- **Partial (2/3)** → gentle boost only
- Void branches block the triad

### Effects (Full Transform)
- Drain ~6% from non-result elements
- Boost ~22% of total Qi to resulting element
- All participating branches protected from clashes
- Overrides Six Combinations involving the same branches

---

## 4. Three Meetings (三会局)

Three consecutive seasonal branches — the most powerful combination:

| Group | Result |
|-------|--------|
| 寅 + 卯 + 辰 | Wood |
| 巳 + 午 + 未 | Fire |
| 申 + 酉 + 戌 | Metal |
| 亥 + 子 + 丑 | Water |

### Rules
- **All 3 must be present** (no partial)
- Season must support the result → transform
- If no season support → bond only (no Qi change)
- Void branches block the meeting

### Effects (Transform)
- Drain ~8% from non-result elements
- Boost ~30% of total Qi to resulting element
- Massive elemental dominance — can trigger overcrowding
- All participating branches strongly protected

| 巳, 午 | Fire |

| 亥, 子 | Water |

## Interaction with Clashes (合能解冲)

This is a fundamental classical rule: **combinations can resolve clashes**.

- If a branch is involved in an active combination, it is "protected"
- Clashes involving protected branches are softened
- The combination takes priority over the clash

Example: If 子 combines with 丑 (六合), and 子 also clashes with 午 (六冲),
the combination protects 子 from the full force of the clash.

## Pipeline Position

```
NTFQ → Void (空亡) → [Stem Combos → Liu He → San He → San Hui] → Clash (克) → Sheng → ...
```

Combinations run AFTER void (because void blocks combinations) and BEFORE
clashes (because combinations can suppress clashes).

---

## Hierarchy of Power

When multiple combinations and clashes compete for the same branch:

1. **Three Meetings** (三会) — highest priority
2. **Three Harmony** (三合) — overrides Six Combos
3. **Six Combinations** (六合) — can suppress clashes
4. **Stem Combinations** (天干合) — gentlest effect
5. **Clashes** (冲/害/刑) — fire after combinations settle

---

## Why This Matters

Without combinations, your Qi analysis is incomplete. Professional BaZi
practitioners never read a chart without checking combinations first because:

- **Clashes sometimes don't happen** — suppressed by active combinations
- **Elements appear that shouldn't be there** — created by transformations
- **Chart structure changes dramatically** — a combination can completely
  redirect the chart's elemental flow
- **Yong Shen calculation shifts** — the "useful god" may change when
  combinations are factored in
