## **PART 1: BACKGROUND & HISTORICAL CONTEXT**

### **What Are Arabic Parts?**

Arabic Parts (also called **Lots**) are **calculated sensitive points** in a natal chart derived by taking the longitudinal distance between two chart points and projecting it from a third point (usually the Ascendant).

**They are NOT:**
- Physical celestial bodies
- Observable astronomical objects
- Modern inventions

**They ARE:**
- Ancient Hellenistic astrological techniques (Greek/Egyptian origin, 3rd century BCE)
- Mathematical relationships between chart points
- Geometric expressions of synthesis
- **Preserved and expanded by medieval Arabic/Persian astrologers** (hence the name)

---

### **The Historical Journey:**

**~300 BCE - Hellenistic Greece/Egypt:**
- Developed by astrologers in Alexandria
- Based on geometric and harmonic principles
- Originally called "Lots" (Greek: *klēroi*)

**~800-1200 CE - Islamic Golden Age:**
- Preserved by Arabic and Persian scholars
- Expanded from ~5 parts to 97+ parts
- Systematized in texts like *Book of Aristotle* (actually by medieval Arabic astrologers)
- Named "Arabic Parts" due to this preservation/expansion

**~1200-1700 CE - Medieval Europe:**
- Transmitted back to Europe through translations
- Used extensively in horary and natal astrology
- Part of Fortune becomes most famous

**~1700-1900 CE - Decline:**
- Enlightenment skepticism reduces usage
- Outer planet discoveries shift focus
- Many parts forgotten

**~1980-Present - Revival:**
- Robert Hand, Robert Zoller revive traditional astrology
- Project Hindsight translates ancient texts
- Modern astrologers rediscover depth of technique

---

### **The Mathematical Philosophy:**

Arabic Parts express the principle: **"What emerges when you combine two energies and project them into a life area?"**

**Formula Structure:**
```
Part = Point A + Point B - Point C
```

**Example - Part of Fortune:**
```
Daytime: ASC + Moon - Sun
Nighttime: ASC + Sun - Moon

Translation: "Where is the synthesis of my conscious will (Sun) 
and emotional needs (Moon) as they manifest through my 
life direction (ASC)?"
```

**The geometry:**
1. Measure the **arc distance** from Point C to Point B
2. Project that **same arc** from Point A
3. The **endpoint** is the Part

**This creates a "harmony point"** where the relationship between two planets manifests tangibly in your life.

"""

class ArabicPartsCalculator:
    """
    Calculate Arabic Parts (Lots) for natal charts
    
    All calculations use ecliptic longitude (0-360 degrees)
    Formula: Part = Point_A + Point_B - Point_C
    Results normalized to 0-360 range
    """
    
    def __init__(self, chart_data: Dict):
        """
        Initialize with chart data
        
        Args:
            chart_data: Dictionary containing:
                - planets: Dict of planet positions (degrees 0-360)
                - houses: Dict of house cusp positions
                - angles: Dict of angle positions (ASC, MC, etc.)
                - is_day_chart: Boolean (Sun above horizon)
        """
        self.planets = chart_data['planets']
        self.houses = chart_data['houses']
        self.angles = chart_data['angles']
        self.is_day_chart = chart_data.get('is_day_chart', True)
        
    def normalize_degrees(self, degrees: float) -> float:
        """
        Normalize degrees to 0-360 range
        
        Args:
            degrees: Any degree value
            
        Returns:
            Normalized value between 0 and 360
        """
        normalized = degrees % 360
        return normalized if normalized >= 0 else normalized + 360
    
    def calculate_part(self, point_a: float, point_b: float, point_c: float) -> float:
        """
        Generic Arabic Part calculation: A + B - C
        
        Args:
            point_a: First point in degrees (usually ASC)
            point_b: Second point in degrees
            point_c: Third point in degrees
            
        Returns:
            Calculated part position in degrees (0-360)
        """
        result = point_a + point_b - point_c
        return self.normalize_degrees(result)
    
    def part_of_fortune(self) -> Tuple[float, str]:
        """
        Calculate Part of Fortune (Pars Fortunae)
        
        Day Chart: ASC + Moon - Sun
        Night Chart: ASC + Sun - Moon
        
        Returns:
            Tuple of (degrees, formula_used)
        """
        asc = self.angles['ASC']
        sun = self.planets['Sun']
        moon = self.planets['Moon']
        
        if self.is_day_chart:
            # Day: ASC + Moon - Sun
            result = self.calculate_part(asc, moon, sun)
            formula = "ASC + Moon - Sun (Day Chart)"
        else:
            # Night: ASC + Sun - Moon
            result = self.calculate_part(asc, sun, moon)
            formula = "ASC + Sun - Moon (Night Chart)"
            
        return (result, formula)

# Utility functions for sign/house calculation

def degrees_to_sign_position(degrees: float) -> Dict:
    """
    Convert ecliptic longitude to sign position
    
    Args:
        degrees: Ecliptic longitude (0-360)
        
    Returns:
        Dictionary with sign, degrees within sign, and zone
    """
    signs = ['Aries', 'Taurus', 'Gemini', 'Cancer', 'Leo', 'Virgo',
             'Libra', 'Scorpio', 'Sagittarius', 'Capricorn', 'Aquarius', 'Pisces']
    
    normalized = degrees % 360
    sign_index = int(normalized // 30)
    degrees_in_sign = normalized % 30
    
    # Calculate zone (1-6, each zone is 5 degrees)
    zone = int(degrees_in_sign // 5) + 1
    
    return {
        'sign': signs[sign_index],
        'degrees': degrees_in_sign,
        'zone': zone
    }


def get_house_from_degrees(degrees: float, houses: Dict) -> int:
    """
    Determine which house a degree position falls into
    
    Args:
        degrees: Ecliptic longitude (0-360)
        houses: Dictionary of house cusps {1: deg, 2: deg, ...}
        
    Returns:
        House number (1-12)
    """
    normalized = degrees % 360
    
    # Create list of house cusps with their numbers
    house_cusps = [(i, houses[str(i)]) for i in range(1, 13)]
    
    # Add house 1 cusp at the end for wrap-around
    house_cusps.append((1, houses['1'] + 360))
    
    # Find which house the degree falls into
    for i in range(len(house_cusps) - 1):
        current_house, current_cusp = house_cusps[i]
        next_house, next_cusp = house_cusps[i + 1]
        
        # Handle wrap-around at 360/0 degrees
        if current_cusp > next_cusp:
            if normalized >= current_cusp or normalized < next_cusp:
                return current_house
        else:
            if current_cusp <= normalized < next_cusp:
                return current_house
    
    return 1  # Default to house 1 if not found

  parts,
  showParts,
  wheelRadius,
  centerX,
  centerY,
}) => {
  if (!showParts) return null;

  const renderPart = (partKey: keyof ArabicPartsData, part: any) => {
    const angle = (part.degrees - 90) * (Math.PI / 180); // Convert to radians, adjust for top = 0°
    const radius = wheelRadius * 0.85; // Place parts slightly inside the wheel
    
    const x = centerX + radius * Math.cos(angle);
    const y = centerY + radius * Math.sin(angle);
    
    return (
      <g key={partKey}>
        {/* Part symbol */}
        <text
          x={x}
          y={y}
          fontSize="16"
          fontWeight="bold"
          fill={ARABIC_PART_COLORS[partKey]}
          textAnchor="middle"
          dominantBaseline="middle"
          className="arabic-part-symbol"
          data-part={partKey}
        >
          {part.symbol}
        </text>
        
        {/* Degree marker line */}
        <line
          x1={centerX + (wheelRadius * 0.8) * Math.cos(angle)}
          y1={centerY + (wheelRadius * 0.8) * Math.sin(angle)}
          x2={centerX + (wheelRadius * 0.9) * Math.cos(angle)}
          y2={centerY + (wheelRadius * 0.9) * Math.sin(angle)}
          stroke={ARABIC_PART_COLORS[partKey]}
          strokeWidth="1"
          opacity="0.6"
        />
      </g>
    );
  };

  return (
    <g className="arabic-parts-layer">
      {Object.entries(parts).map(([key, part]) => 
        renderPart(key as keyof ArabicPartsData, part)
      )}
    </g>
  );
};
