## 7. Compatibility Scoring System

### Understanding the Mathematics of Love

You've learned WHAT makes relationships work (element relationships).

Now you'll learn HOW to calculate compatibility scores for any person you meet.

This isn't fortune-telling. This is **constitutional mathematics**.

Every relationship has a predictable compatibility percentage based on:
- Element base scores (from Section 6)
- Modifying factors (Yin-Yang harmony, branch compatibility, maturity)
- Your specific 乙巳 needs (0% Water, 5% Earth, 50% Wood)

**By the end of this section, you'll be able to:**
- Calculate compatibility percentage for anyone
- Predict relationship dynamics before committing
- Understand why scores vary within element types
- Make informed choices about partnerships

**BASE SCORES FOR 乙巳:**

- 💧 **Water → Wood: 85-92%** (BEST - nourishes your 0% deficit)

- ⛰️ **Earth + Wood: 60-75%** (CHALLENGING - restriction vs grounding)
- ⚙️ **Metal → Wood: 40-65%** (AVOID if excessive - cutting danger)
