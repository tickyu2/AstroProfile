## 🎭 **THE 36 CUSPS**

### **Structure**

Western Zodiac has 12 signs, but GENESIS uses 36 cusps:

```
Each sign = 30 days ÷ 3 periods = 3 cusps
12 signs × 3 cusps = 36 total cusps

Example for Aries (Mar 21 - Apr 19):
1. Aries-Pisces (Mar 20-24) - blend-back
2. Aries Pure (Mar 25 - Apr 13) - pure
3. Aries-Taurus (Apr 14-20) - blend-forward
```

### **Cusp Types**

**Pure Signs (12 total):**
- Middle period of each sign
- Strongest expression of that element
- Examples: Aries Pure (Fire), Taurus Pure (Earth)

**Blend-Forward Cusps (12 total):**
- Transition INTO next sign
- Primary element + secondary element
- Examples: Aries-Taurus (Fire + Earth)

**Blend-Back Cusps (12 total):**
- Transition FROM previous sign
- Primary element + secondary element
- Examples: Taurus-Aries (Earth + Fire)

### **Element Distribution**

**4 Elements × 3 Signs Each = 12 Per Element**

