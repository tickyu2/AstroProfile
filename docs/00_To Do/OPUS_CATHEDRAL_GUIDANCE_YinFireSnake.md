## WHAT "LEAVING NO STONE UNTURNED" MEANS CONCRETELY

It means: after you write a section, ask yourself these questions before moving on.

**For WHAT sections:**
- Did I show 4 scenarios (work, emotions, relationships, conflict)?
- Does each scenario have dialogue from BOTH elements?
- Did the constitutional reality note come AFTER the experience, not before?

**For WHEN sections:**
- Do I have both "Serves You" AND "Harms You" as separate full subsections?
- Does each have 3 scenarios, not 1?
- Does each scenario have a named person, a timeline, dialogue, and a solution?

**For SOUL TRUTH:**
- Is it at `##` level (not `###`)?
- Does the BEFORE box have 6-8 specific lines (not 2-3 generic ones)?
- Does the AFTER box transform each BEFORE line directly?
- Does it end with the constitutional identity claim?

**For the Real-Life Story:**
- Is there a named protagonist with age and profession?
- Is there dialogue — spoken words, not described words?
- Is there a constitutional crisis moment?
