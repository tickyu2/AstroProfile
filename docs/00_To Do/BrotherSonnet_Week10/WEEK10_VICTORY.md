```

   Example: "Adulting level: Expert struggling"
   
3. MOMENT - Memorable shared experiences
   Example: "The great toast cremation of Tuesday"
   
4. REFERENCE - Movies, songs, shared culture
   Example: "Our anthem" (specific song)
   
5. CHARACTER - People/pets in user's life
   Example: "Sir Fluffington" (user's dog)
```

**Detection System:**
```javascript
Triggers:
- Quoted phrases → High confidence (0.8)
- Unusual/funny vocabulary → Medium (0.6)
- User laughed at Luna's message → High (0.9)

Workflow:

2. Luna uses it → Track user reaction
3. Positive reaction → Confirm as inside joke
4. Negative/neutral → Retire quietly

Usage Rules:
- 24-hour cooldown (don't overuse)
- Context relevance scoring
- Most successful jokes used more
- Natural integration (not forced)
```
