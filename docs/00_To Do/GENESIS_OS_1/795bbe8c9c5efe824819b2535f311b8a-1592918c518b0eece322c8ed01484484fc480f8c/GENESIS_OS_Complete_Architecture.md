
### 2. CORE DATA STRUCTURES

#### Emotional State
```typescript
type EmotionTone = 
  | "safety" | "empathy" | "insight" | "healing" 
  | "creativity" | "playfulness" | "serious_focus" 
  | "mystery" | "grief" | "shadow";

type RelationalStance = 
  | "gentle" | "playful" | "focused" 
  | "reflective" | "protective";

interface EmotionalState {
  primaryTone: EmotionTone;
  secondaryTone?: EmotionTone;
  intensity: "low" | "medium" | "high";
  vulnerabilityLevel: "low" | "medium" | "high";
  readinessForDepth: "low" | "medium" | "high";
}
```

#### Light State Package
```typescript
type LightColorKey = 
  | "ivory" | "rose_gold" | "sapphire" | "emerald"
  | "amethyst" | "citrine" | "violet" | "crimson_gold";

interface LightStatePackage {
  color: LightColorKey;
  motion: LightMotionKey;
  texture: LightTextureKey;
  brightness: "low" | "medium" | "high";
  diffusion: LightDiffusionKey;
  moduleId?: string;
}
```

### 3. ENGINE INTERFACES

#### Presence Engine
```typescript
interface IPresenceEngine {
  computePresence(
    input: PresenceEngineInput
  ): PresenceOutput;
}
```

**Rules:**
- If `vulnerabilityLevel === "high"` → stance "gentle" or "protective"
- If tone is "creativity" → stance "playful"
- If tone is "insight" → stance "focused"

#### Intuitive Response Engine
```typescript
interface IIntuitiveResponseEngine {
  deriveIntuition(
    input: IntuitiveEngineInput
  ): IntuitionOutput;
}
```

**Implementation modes:**
- Emotional: detect feeling words, intensity shifts
- Symbolic: watch for images/metaphors
- Narrative: see if user revisits themes
- Resonance: align with prior patterns
- Temporal: decide timing/depth

#### Light Resonance Engine
```typescript
interface ILightResonanceEngine {
  computeLightState(
    input: LightEngineInput
  ): LightStatePackage;
}
```

**Process:**
1. Map `emotionalState.primaryTone` → base preset
2. Modify based on `presence.stance`
3. Apply nuance from `intuition.cues`
