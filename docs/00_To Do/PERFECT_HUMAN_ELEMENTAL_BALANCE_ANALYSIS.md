Each element should be strong enough to **nourish its child** while being **supported by its mother**:


**For optimal flow:**

```

```

**For optimal regulation:**
- Controller should be ~3-5% stronger than controlled
- Prevents excess in any element
- Maintains dynamic equilibrium
