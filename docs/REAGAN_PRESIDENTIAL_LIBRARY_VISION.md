## Part III: RAG Architecture

### pgvector + Neo4j Dual Database Strategy

We use **two complementary systems**:

| System | Purpose | Strengths |
|--------|---------|-----------|
| **pgvector** | Semantic similarity search | Fast embedding queries, SQL integration |
| **Neo4j** | Relationship graph | Character connections, event chains, thematic links |

### Why Both?

```
QUESTION: "What did Reagan think about Gorbachev's wife Raisa?"

pgvector finds:
  → Chunks mentioning "Reagan" + "Raisa" + sentiment
  → Semantic similarity to "Soviet first lady" topics
  → Diary entries about state dinners

Neo4j adds:
  → Reagan → [MET_AT] → Moscow Summit 1988 → [ATTENDED_BY] → Raisa
  → Nancy → [HAD_TENSION_WITH] → Raisa (relationship context)
  → Raisa → [INFLUENCED] → Gorbachev's reform thinking

Combined: Richer, more contextual response
```

### Sample Neo4j Queries

```cypher
// Find all events where Reagan and Gorbachev both participated
MATCH (reagan:Person {name: 'Ronald Reagan'})-[:PARTICIPATED_IN]->(event:Event)
      <-[:PARTICIPATED_IN]-(gorbachev:Person {name: 'Mikhail Gorbachev'})
RETURN event.name, event.date, event.location
ORDER BY event.date

// Find documents mentioning both Reagan and astrology
MATCH (doc:Document)-[:MENTIONS]->(reagan:Person {name: 'Ronald Reagan'})
MATCH (doc)-[:DISCUSSES]->(topic:Topic {name: 'Astrology'})
RETURN doc.title, doc.type, doc.date

// Trace the relationship evolution between Reagan and Gorbachev
MATCH path = (reagan:Person {name: 'Ronald Reagan'})
              -[r:KNEW*1..3]-(gorbachev:Person {name: 'Mikhail Gorbachev'})
RETURN path

// Find topics discussed at Rancho del Cielo
MATCH (reagan:Person {name: 'Ronald Reagan'})-[:VISITED]->(ranch:Location {name: 'Rancho del Cielo'})
MATCH (doc:Document)-[:DISCUSSES]->(topic:Topic)
WHERE doc.location = 'Rancho del Cielo'
RETURN DISTINCT topic.name, count(*) as mentions
ORDER BY mentions DESC
```

### Chunking Strategy

#### The Problem
Large documents need to be split into retrievable chunks. Poor chunking = poor retrieval.

#### Our Approach: Semantic-Aware Chunking

```python
class SemanticChunker:
    """
    Chunks documents while preserving:
    - Paragraph boundaries
    - Speaker attribution (for interviews/dialogues)
    - Topic continuity
    - Chronological context
    """

    def __init__(self,
                 target_tokens: int = 600,
                 max_tokens: int = 800,
                 overlap_tokens: int = 50):
        self.target_tokens = target_tokens
        self.max_tokens = max_tokens
        self.overlap_tokens = overlap_tokens

    def chunk_document(self, text: str, metadata: dict) -> List[Chunk]:
        # 1. Split by paragraphs first
        paragraphs = self._split_paragraphs(text)

        # 2. Detect speaker changes (for interviews)
        paragraphs = self._attribute_speakers(paragraphs)

        # 3. Group into semantic units
        semantic_units = self._group_semantic_units(paragraphs)

        # 4. Create overlapping chunks
        chunks = self._create_chunks(semantic_units)

        # 5. Enrich with metadata
        chunks = self._enrich_metadata(chunks, metadata)

        return chunks
```

### ePub Ingestion

```python
import ebooklib
from ebooklib import epub
from bs4 import BeautifulSoup

def ingest_epub(file_path: str) -> List[Chapter]:
    """
    Ingests ePub files while preserving:
    - Chapter structure
    - Formatting hints
    - Table of contents
    - Embedded metadata
    """
    book = epub.read_epub(file_path)
    chapters = []

    for item in book.get_items():
        if item.get_type() == ebooklib.ITEM_DOCUMENT:
            # Parse HTML content
            soup = BeautifulSoup(item.get_content(), 'html.parser')

            # Extract text with structure
            chapter = {
                'title': extract_title(soup),
                'text': soup.get_text(separator='\n'),
                'headings': extract_headings(soup),
                'quotes': extract_blockquotes(soup)
            }
            chapters.append(chapter)

    return chapters
```

### PDF Ingestion

```python
import PyPDF2
from pdf2image import convert_from_path
import pytesseract

def ingest_pdf(file_path: str) -> Document:
    """
    Ingests PDF files with:
    - Text extraction (native or OCR)
    - Page number preservation
    - Image extraction for scanned docs
    """

    # Try native text extraction first
    with open(file_path, 'rb') as file:
        reader = PyPDF2.PdfReader(file)

        if has_extractable_text(reader):
            return extract_native_text(reader)
        else:
            # Fall back to OCR
            return ocr_pdf(file_path)

def ocr_pdf(file_path: str) -> Document:
    """OCR for scanned documents"""
    images = convert_from_path(file_path)

    pages = []
    for i, image in enumerate(images):
        text = pytesseract.image_to_string(image)
        pages.append({
            'page_number': i + 1,
            'text': text,
            'confidence': pytesseract.image_to_data(image, output_type='dict')
        })

    return Document(pages=pages)
```

### Embedding Pipeline

```python
from openai import OpenAI
import asyncio
from typing import List

client = OpenAI()

async def generate_embeddings(chunks: List[str]) -> List[List[float]]:
    """
    Generate embeddings for document chunks.
    Handles rate limiting and batching.
    """
    embeddings = []
    batch_size = 100

    for i in range(0, len(chunks), batch_size):
        batch = chunks[i:i + batch_size]

        response = await client.embeddings.create(
            model="text-embedding-ada-002",
            input=batch
        )

        batch_embeddings = [e.embedding for e in response.data]
        embeddings.extend(batch_embeddings)

        # Rate limiting
        await asyncio.sleep(0.5)

    return embeddings
```

### Retrieval Function

```python
async def retrieve_context(
    query: str,
    character_id: str,
    top_k: int = 5
) -> List[Chunk]:
    """
    Hybrid retrieval using pgvector + Neo4j.
    """
    # 1. Generate query embedding
    query_embedding = await generate_embedding(query)

    # 2. pgvector similarity search
    vector_results = await pgvector_search(
        embedding=query_embedding,
        character_id=character_id,
        limit=top_k * 2
    )

    # 3. Neo4j graph traversal for related context
    graph_results = await neo4j_expand(
        entities=extract_entities(query),
        character_id=character_id,
        depth=2
    )

    # 4. Merge and rank results
    combined = merge_results(vector_results, graph_results)

    # 5. Re-rank by relevance
    ranked = rerank(combined, query)

    return ranked[:top_k]
```
