## The 5W+H+Soul Methodology

For burden extraction:
1. **5W+H** (journalism): Who, What, When, Where, Why, How
2. **+Soul** (emotional): How did it FEEL? What burden does this carry?

Process:
1. Create safe space (trust established)
2. Extract with 5W+H (factual foundation)
3. Add Soul witnessing ("How did that feel?")
4. Cross-synthesize (connect to patterns)
5. Create capacity (burden externalized, soul lightened)
