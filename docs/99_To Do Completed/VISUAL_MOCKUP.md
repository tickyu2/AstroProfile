## 🎨 COLOR SCHEME

### **Tier Badges:**
```
🏆 Golden (90-100%)    - Yellow/Amber gradient
⭐ Excellent (80-89%)  - Purple/Pink gradient  
✨ Very Good (70-79%)  - Blue/Cyan gradient
```

### **Score Bars:**
```
Primary Element    - Blue gradient
Secondary Element  - Cyan gradient
Quality/Modality   - Purple gradient
Rulers             - Yellow gradient
Cusp Type          - Pink gradient
Mutual Influence   - Green gradient (with special highlight)
Aspect             - Emerald (positive) / Red (negative)
```

### **Challenge Severity:**
```
🔴 High    - Red/Orange background
🟡 Medium  - Amber/Yellow background
🔵 Low     - Slate/Gray background
```

## 🎬 ANIMATION SEQUENCE

### **1. Panel Appears (300ms ease-out):**
```
Opacity: 0 → 1
Transform: translateY(20px) → translateY(0)
```

### **2. Expand Clicked (400ms ease-in-out):**
```
Height: auto expand
Arrow icon: rotate(0) → rotate(180deg)
```

### **3. Score Bars Fill (500ms ease-out, stagger 100ms):**
```
Width: 0% → [percentage]%
Delay per bar: index * 100ms
```

### **4. Challenge Cards Appear (300ms ease-out, stagger 150ms):**
```
Opacity: 0 → 1
Transform: translateX(-20px) → translateX(0)
Delay per card: index * 150ms
```

## 🎯 USER EXPERIENCE FLOW

```
1. User sees constellation of compatible matches
   ↓
2. Clicks on interesting bubble (e.g., "100% Cancer")
   ↓
3. Panel appears below with tier badge
   ↓
4. User clicks "Show Detailed Calculation"
   ↓
5. Panel expands with:
   - Animated score bars
   - Detailed explanations
   - Challenge warnings
   - Key strengths
   ↓
6. User understands WHY match works
   ↓
7. User sees potential challenges
   ↓
8. User can click different bubbles to compare
```
